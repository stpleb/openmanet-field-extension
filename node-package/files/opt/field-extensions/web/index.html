Node status

Status LED (Automatic)

--
--

LED colour reflects network and system status. Blue pulses indicate GPS fix. Red pulses indicate low battery. White means maintenance: the node is being updated or worked on, so don't unplug it. Blue slow blinks mean only LoRa is left. While charging, the colour stays steady and every 10 seconds it blinks green once per 20% of charge; the blinks stop when full.
