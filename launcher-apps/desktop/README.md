# ManetNode desktop launcher (Mac)

Double-click `ManetNode.app` (drag it to Applications if you like). It lists 10.41.0.1 plus any
nodes you add, shows each node's status-light colour, name, battery and mesh size, and opens the
node's OpenManet or FieldExtension page in your web browser.

First launch: macOS may say it can't check the app (it isn't from the App Store). Right-click the
app > Open > Open. After that it opens normally.

Source: `ManetNode/ManetNodeApp.swift` (same node list and look as the iPhone app).
Rebuild: open `ManetNode.xcodeproj` in Xcode and press Run.

Windows: see ../windows/ (ManetNode.cmd).
