Join a phone

  1. Join the node's Wi-Fi (name on the web page, EUD Wi-Fi tile).
  2. Open ATAK. The ManetNode FE plugin finds the node by itself; the corner dot shows its light colour.
  3. No plugin? Open http://10.41.0.1:8787 in the browser, or use the ManetNode app.
  4. Phone Internet: AUTO uses the node's internet when it has some, else the phone's cellular; CELL always uses cellular. Phones switch at their next Wi-Fi reconnect.

Charging & power

  • Charge from the case port with a 5 V / 3 A supply and a short cable. The battery tile shows % and time left (set the pack size: web page Maintenance).
  • % shown while charging moves slowly on purpose; the voltage is the honest number (3.4–3.5 V ≈ 15–35 %).
  • Auto power-on ON: the node starts by itself when the charger is plugged in after a full drain.
  • Off: hold the PiSugar button (light blinks red, then off), or Shutdown in the plugin. On: short-press the button.
Some USB-C chargers give 0 V to the case port until it has two 5.1 kΩ resistors (CC1→GND, CC2→GND). A USB-A-to-C cable always works.

LoRa (Meshtastic radio)

AUTOPositions and chat go over LoRa when the mesh is down, or while a LoRa-only teammate is heard.
ALWAYSAlso while the mesh is up.
OFFRadio left alone.
DARKTeam channel only, frequency from the team name. Works with older nodes on a custom layout.
COVERTTeam + public channel; your position never goes on the public channel. Public frequency.
OPENTeam + public channel; public radios see you. Public frequency.
OPEN / COVERT move the radio to the public LongFast frequency: nodes on a custom layout stop hearing it. Use DARK in a mixed team.
"Change every node" ON sends team channel and mode changes to every node over LoRa. OFF changes only this node.

Add a LoRa-only teammate

  1. They need a Meshtastic radio paired to their phone, ATAK, and the Meshtastic ATAK plugin.
  2. Plugin LORA tab → Team channel → QR (or web page → Share code). It holds the team key: only show it to your team.
  3. They scan it in the Meshtastic app (Channels → QR). Same region and speed as the team.
  4. Their dot and chat appear for everyone on the mesh; yours reach them over LoRa.
LoRa is slow (~1 kbit/s): positions about once a minute, chat up to 200 characters, map markers yes; photos, video, files and voice no.

Something's wrong?

  • Plugin says "not answering": check you're on the node's Wi-Fi; long-press the node name to set the address.
  • Amber light: no other node heard. Move closer or check the other node is on.
  • LoRa "not connected": reseat the radio's USB cable; the node retries and power-cycles the port itself.
  • Node changes ask for the node password (same as the OpenMANET page).
