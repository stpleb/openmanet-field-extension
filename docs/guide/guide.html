1 · What it is and how it fits together

OpenMANET turns a Raspberry Pi 4 with a Wi-Fi HaLow radio into a mesh node: nodes find each other and form one network over long range, and phones join a node's Wi-Fi to get on it. The Field Extension adds what a team needs in the field:

  • A status light on each node that tells you at a glance whether it has mesh, internet, LoRa, GPS, how charged it is, and when it is being worked on.
  • Battery and power control for the PiSugar battery: percent and time left, auto power-on, safe low-battery shutdown, clean shutdown on a long press.
  • LoRa fallback: when the mesh is out of reach, ATAK positions, chat and map markers go over a Meshtastic LoRa radio instead.
  • Self-repair: watchdogs restart a stuck HaLow radio, demote a bad 2.4 GHz link, recover after crashes.
  • A node web page (port 8787), the ATAK plugin and the ManetNode app to see and change all of it.

The three ways to control it

ToolWhereBest for
ATAK plugin “ManetNode FE”Inside ATAK (Tools menu)Day-to-day: light, battery, LoRa, push-to-talk, without leaving ATAK
ManetNode appAndroid appTeam map with points, geofences and breadcrumbs, chat, PTT, every node setting, adding nodes, the Capabilities Test
Node web pageBrowser: http://<node>:8787Everything in depth, from any phone or laptop, no install

OpenMANET's own page stays at port 8080 (mesh, Wi-Fi and system settings). The Field Extension never changes OpenMANET itself.

2.1Wiring the status light

Use a common-cathode RGB LED: one long leg goes to ground, the other three legs are red, green and blue. Put a 330 Ω resistor in each colour leg. The three colour pins are fixed in the software: red = GPIO 27, green = GPIO 22, blue = GPIO 26.

Check itAfter the first boot the light should go red (starting), then turn the colour of the node's state. The self-test (chapter 13) should say “PASS Status light driver is running”.

2.2Charging through a case USB-C port

Many cases bring the PiSugar's charge input out to a USB-C socket on the case. A plain USB-C socket gives 0 V on a USB-C-to-C charger unless its two CC pins each have a 5.1 kΩ resistor to ground; that is how the charger knows a device is plugged in. A USB-A-to-C cable always works, because it does not need the CC pins.

ChargerUse a 5 V / 3 A supply and a short cable. A weak supply can't run the node and charge the battery at the same time, and the battery slowly drains even while plugged in.

3 · Setting up nodes

3.1A brand-new node from the SD card image

  1. Download FieldExtension-OpenMANET-v1.0-SD-image-rpi4.img.gz from the release.
  2. Flash it to a microSD card with Raspberry Pi Imager (Choose OS → Use custom) or balenaEtcher. Both accept the .gz file directly.
  3. Put the card in the Pi and power it on. The light goes red while it starts (about a minute).
  4. Join the new node's Wi-Fi and finish OpenMANET's own first-boot setup on its page (port 8080): root password and country/region.
  5. Add it to your team with a setup code (next section). That gives it the same mesh, the same LoRa team channel and its own callsign in one step.

The image is stock OpenMANET 1.8 (Pi 4, HaLow MM6108 SPI) with the Field Extension and its Python preinstalled. It holds no keys, passwords, callsigns or mesh settings. It also carries the optional PortableTAK loader, which does nothing unless a signed PortableTAK drive is plugged in.

3.2Adding a node to the team with a setup code

After the reboot (about 2 minutes) the new node's light turns green or purple as soon as it hears the others, and it appears in everyone's node list and map.

3.3Installing on an existing OpenMANET 1.8 node

  1. Put field-extensions_1.0.9_all.ipk into the node-installer/ folder (from the GitHub page).
  2. Join the node's Wi-Fi (or plug into its LAN port).
  3. Mac: double-click Install Field Extension (Mac).command (first time: right-click → Open). Windows: right-click the .ps1 → Run with PowerShell.
  4. Press Return for 10.41.0.1 (or type the node's address) and type the node's root password when asked.

It saves a backup of the node's settings next to the installer, installs the package, and runs the self-test. Stock OpenMANET has no Python, so the first install fetches it from the OpenWrt package feed: the node needs internet for that (plug its LAN port into a router).

5 · Power and battery

FeatureWhat it does
Battery %From the PiSugar, smoothed over 5 minutes so it doesn't jump. After a calibration it uses the node's own measured curve. While charging the % rises slowly on purpose; the voltage is the honest number.
Time leftFrom the pack size you set (5,000 / 8,000 / 10,000 mAh or other) and, after about 10 minutes on battery, the node's real drain.
Auto power-onON: after the battery ran flat, the node starts by itself as soon as the charger is plugged in. Recommended ON for every node.
Safe shutdownOn battery, at 5 % (or 10 %) the node shuts down cleanly instead of losing power suddenly, which can damage the SD card.
Button long pressClean shutdown (recommended): hold the PiSugar button; the light blinks red and the node saves everything and powers off. Cut power: the PiSugar default, off at once.
CalibrationFor a new or different battery: charge to full, press Calibrate, unplug, and leave the node running until it switches itself off (about 12 h on 10,000 mAh). Plugging in cancels the run.
Turning a node on and off On: short-press (tap) the PiSugar button. Off: hold the button until the light blinks red, or use Shutdown in the plugin, app or web page. It stays off until the button is pressed again (or the charger is plugged in after a full drain, with auto power-on ON).

7 · The ATAK plugin (ManetNode FE)

Open ATAK, tap the Tools menu, then ManetNode FE. The plugin finds the node your phone's Wi-Fi is on. To point it at another node, long-press the node name and type its address. The plugin's corner dot on the map is the node's light colour.

TabWhat's on it

STATUSThe light and its meaning, battery, mesh links, internet, LoRa, services and node health.
LORAFallback mode, LoRa mode (Open / Covert / Dark), team channel with QR code, radios heard, send a test message.
SETCallsign, team and role; light on/off and brightness; auto power-on and long press; position source; node markers and mesh lines on the ATAK map; clear fleet chat; new-node setup code; Maintenance mode; reboot and shutdown. A button opens the node's full web page.
Nodes on the ATAK mapWith SET → Nodes on map ON, every node shows as a marker in its light colour, with lines between nodes: solid = HaLow, dashed = 2.4 GHz, dotted = LoRa only.

9 · Map tools: points, geofences, breadcrumbs

Tap the round + button on the left of the map for the Map Tools menu, or long-press anywhere on the map to drop a point there.

Points and geofences are stored on the phone and shared over the mesh, so they survive an app restart and show up for teammates who join later (each phone re-sends its own items every 2 minutes).

Tap any point or fence for its details. Long-press the map for a quick point at that spot.

Geofence areaTap the map to place each corner; Undo, Cancel, Done.

9.1Who sees your points and geofences

DeletingDeleting a point or geofence removes it for everyone, including items other people placed. Settings → Map lists every item and has “Delete all my points & geofences”.

10 · Capabilities Test (range walk)

Measures how far each link really reaches where you are: 2.4 GHz, HaLow and LoRa. It records a point every 3 seconds with the best link at that spot, draws a coloured track on the map, and saves it.

  1. Leave one node (the base) where it will stand. Carry the other node, with your phone on the carried node's Wi-Fi, and the app open.
  2. Stand next to the base node. ManetNode → Settings → Capabilities Test → Start test. The screen stays on.
  3. Walk out until you lose everything, then come back if you like. The page shows the ranges reached so far.
  4. Stop & save. The “Last test” card shows the furthest range for 2.4 GHz, HaLow and LoRa, and the Settings menu shows them too.

The track is saved to Download/ManetNode as .kml (opens in Google Earth and ATAK) and .csv (spreadsheet: time, position, link, speed, signal). Points with a GPS accuracy worse than 50 m are skipped.

After a test, the Last test card lists the furthest range for 2.4 GHz mesh, HaLow mesh and LoRa, the date, how far you walked, how long it took and how many points were recorded. A link that never showed up says “not seen”.

Clear track removes the coloured track from the map; the saved files stay.

11 · LoRa fallback

Each node can have a Meshtastic LoRa radio on USB. LoRa is slow (about 1 kbit/s) but reaches much further than Wi-Fi, so the nodes use it as a backup: positions, chat and map markers go over LoRa to nodes and LoRa-only teammates the mesh can't reach. Photos, video, files and voice don't.

FallbackBehaviour
AUTOUse LoRa when the mesh is down, or while a LoRa-only teammate is heard. Recommended.
ALWAYSAlso while the mesh is up.
OFFLeave the radio alone.
LoRa modeBehaviour
DARKTeam channel only, on a private frequency worked out from the team name. Keeps LoRa off the public channel and away from strangers. Use this in a mixed team.
COVERTTeam channel + the public channel; your position never goes on the public channel. Public frequency.
OPENTeam + public channel; public Meshtastic radios see you. Public frequency.
Mixed teamsOPEN and COVERT move the radio to the public LongFast frequency. Radios on a custom layout stop hearing it. Every radio in the team must use the same region, speed and team channel.

11.1Team channel

Only radios with the same team name and passphrase can read team traffic. With Change every node ON, a new name or passphrase is sent over LoRa to every node so they all switch together. If a node is lost, turn Change every node OFF and set a new passphrase on each remaining node by hand, so the lost node can't follow.

11.2Adding a LoRa-only teammate

  1. They need a Meshtastic radio paired to their phone, ATAK, and the Meshtastic ATAK plugin.
  2. Plugin LORA → Team channel → QR, or web page → Share code. It holds the team key: only show it to your team.
  3. They scan it in the Meshtastic app (Channels → QR), on the same region and speed.
  4. Their position and chat appear for everyone on the mesh; yours reach them over LoRa.

11.3Node radios on the ATAK map

The nodes' own LoRa radios are kept off ATAK maps by default, because the node already shows itself. Guests' Meshtastic radios always show. Switch with “Node radios in ATAK”.

11.4Chat alerts

Nodes can post battery, mesh and temperature warnings in ATAK's All Chat Rooms. This is OFF by default so the team chat stays clean; the warnings still show on the node's page and in the plugin.

12 · The mesh: HaLow and 2.4 GHz

Nodes link over HaLow (sub-GHz, long range, about 15 Mb/s) and, with the USB stick, over 2.4 GHz (short range, about 30 Mb/s or more). The mesh (batman-adv) picks the best path by itself and switches when a link fades. Phones join the node's own Wi-Fi.

FeatureWhat it does
Link watchdogsReboot the node if the HaLow radio stops, or if all HaLow peers vanish for 20 minutes (each at most twice in 6 h); unstick a stuck HaLow rate; move traffic off a weak 2.4 GHz link; check each mesh link.
Phone InternetAUTO: phones use the node's internet when it has one, otherwise their own cellular data. CELL: phones always use cellular; the node carries mesh traffic only. Phones switch at their next Wi-Fi reconnect.
Join another meshScan another team's mesh QR to join it, for good or temporarily: a temporary join switches back after the hours you choose. Keep cancels the switch-back.
Share this meshShows the mesh settings as a QR code (includes the mesh password).
Position sourceAuto, the node's GPS, or the connected phone: a node with no GPS can take its position from the phone on its Wi-Fi.
Rules that keep nodes talking
  • All nodes: same mesh ID, channel, width, key and the 1 MHz primary channel index 1 (the OpenMANET 1.8 default), with HaLow on network batmesh0. The self-test checks these.
  • RT5370 sticks: use HT20. If a link peers but carries no data, set rt2800usb nohwcrypt=1 in /etc/modules.d/rt2800-usb and reboot.
  • Never restart Wi-Fi remotely (wifi down/up): it can hang the radios. Reboot instead.

13 · Maintenance, updates and backups

13.1Maintenance mode (white light)

Tells the team “this node is being worked on, don't unplug it or count on it right now”. The light turns white by itself while the node is updating, applying settings or running diagnostics. You can also switch it on by hand: ManetNode → Node Settings → Maintenance mode → On 30 min, the plugin's SET tab, or the web page's Maintenance section. It ends after 30 minutes or when you press Off.

13.2Updating

  • From a computer: the node installer (3.3) with the newer .ipk.
  • Over the mesh: update one node, and the others can take the same version from it (web page → Updates from the mesh). Ask waits for you to press Update; Auto installs by itself. The download must match its checksum.
  • OpenMANET itself: web page → OpenMANET Updates.

13.3Self-test and diagnostics

ssh root@10.41.0.1 'sh /opt/field-extensions/selftest.sh'

PASS  Python is installed.
PASS  Battery-board connection (I2C bus 1) is on.
PASS  Battery board (PiSugar) answers. Battery 61%.
PASS  Web page and API is running.
PASS  Status light driver is running.
PASS  Phone internet helper is running.
PASS  LoRa service is running.
PASS  Self-recovery is running.
PASS  Button long press: clean shutdown (PiSugar soft-shutdown mode on).
PASS  Power-off step is on (the node turns fully off after a Field Extension shutdown).
PASS  Field Extension page answers at http://10.41.0.1:8787/
PASS  Status light reports maintenance (white light) state.
PASS  HaLow mesh carries mesh traffic (network batmesh0).
PASS  HaLow primary channel index is 1 (matches the other nodes).
RESULT: all checks passed.

One line per check: PASS, FAIL (with what to fix) or SKIP (not used on this node). The installer runs it after every install. Web page → Maintenance → Open diagnostics collects versions, mesh, HaLow, LoRa, logs and restarts in one page to send to whoever is helping, with no passwords or keys.

13.4Backups

The installer saves a backup before every install. OpenMANET's own backup (System → Backup) includes the Field Extension's settings, because the package lists them in /etc/sysupgrade.conf. To move a node to a new SD card: back up, flash the new card, restore the backup on first boot.

13.5Clear fleet chat

Deletes the team chat stored on every node and every ManetNode phone, so the next operation starts clean. A node or phone that is off picks it up when it rejoins. ATAK keeps its own chat history.

14 · Troubleshooting

ProblemTry
Plugin or app says “not answering”Check the phone is on a node's Wi-Fi (not cellular-only). In the plugin, long-press the node name and type its address.
Light amberNo other node heard and no LoRa. Check the other nodes are on and within range; reseat the LoRa radio's USB cable.
Light stays redOpen the web page → Node Health and Services to see what failed. A reboot clears most faults.
LoRa “not connected”Reseat the radio's USB cable. The node retries and power-cycles the USB port by itself.
LoRa connected but nobody heardAll radios need the same region, speed and team channel. Use DARK in a mixed team.
A node hears the mesh but nothing reaches itReboot it (PiSugar off, then on). If it keeps happening on the 2.4 GHz link, set the RT5370 fix (chapter 12).
Node won't start after the battery ran flatPlug in the charger and tap the PiSugar button. Turn auto power-on ON so it starts by itself next time.
Case USB-C charger does nothingThe case socket needs the 5.1 kΩ CC resistors (Figure 4). A USB-A-to-C cable always works.
Battery % jumps or stops near 92 %Run a battery calibration (chapter 5).
Node changes ask for a passwordIt's the node's root password, the same as the OpenMANET page.
ATAK won't install the pluginUse the signed APK that matches your ATAK version (5.7 or 5.8). A developer (debug) build of ATAK needs a debug plugin instead.
